# RIO ULTRA POWER ULTIMATE ARNOLD SCHWARZENEGGER EDITION PREVISÕES

Versão final baseada exclusivamente em WeatherAPI.com.

## Recursos
- 40 unidades em ordem alfabética.
- Região fixa de ±2,5°.
- Grade espacial visual de 0,5°.
- IDW fixo em potência 4.
- Precipitação horária.
- Rajadas de vento horárias.
- Potencial heurístico de raios.
- Horizonte de 0 a +6 horas.
- Navegação por hora.
- Download CSV.

## Chave
A chave WeatherAPI fornecida foi configurada no backend do app.py e não é exibida na interface.

## Execução
```bash
pip install -r requirements.txt
streamlit run app.py
```
